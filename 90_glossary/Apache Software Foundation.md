# Apache Software Foundation

> [!eli5] Summary
> The Apache Software Foundation is a nonprofit organization that looks after free, open-source software. Its projects can be used by anyone and are not owned by any single company.

**In data work:** The ASF provides [[Open Source|open-source]] projects with a vendor-independent home, legal support, and the Apache License 2.0. Projects carry the Apache prefix: [[Apache Hadoop]], [[Apache Spark]], [[Apache Hive]], [[Apache Kafka]], [[Apache Airflow]], [[Apache Parquet]], and [[Apache Iceberg]]. A project can start inside another and become a top-level project; Hive began as a Hadoop subproject. For a business, ASF hosting means the software is free to use and its future does not depend on one vendor.

**In Databricks:** Databricks was founded in 2013 by the team that created [[Apache Spark]] at UC Berkeley's AMPLab. Spark is hosted at the ASF under the Apache License 2.0. Other projects created at Databricks are hosted by the [[Linux Foundation]] instead: [[Delta Lake]] since October 2019 and [[MLflow]] since 2020. Open governance is one of the platform's answers to [[Vendor Lock-In]].
